# Герои Эрафии — браузерная версия Heroes of Might and Magic III

Одиночная пошаговая стратегия в браузере: карта приключений с туманом войны, восемь фракций по семь уровней существ, герои с навыками и магией, тактические бои на гексовом поле 15×11, осады, ИИ-противники. Без сервера и сборки: открой `index.html`.

**Играть:** `games/homm3/index.html` (GitHub Pages: `/games/homm3/`).

## Документы
- `docs/01-research.md` — исследование: механики HoMM3 (статы, формулы, постройки, магия, бой), принципы геймдизайна и производства игр, технология браузерных игр.
- `docs/02-spec.md` — техническое задание: скоуп (MoSCoW), правила, контент, экраны, архитектура, план производства, критерии приёмки.
- `docs/sprite-guide.md` — гайд по пиксель-спрайтам.

## Что нового в v1.6 «Мир»
- **Два слоя карты**: подземелье с пещерами, выгрызенными в скале, и врата, переносящие героя между слоями. Свой туман войны, своя миникарта, свой сумрачный свет.
- **Море и корабли**: побережье вдоль края карты, лодки, верфь на берегу и в приморском городе, обломки кораблей и сундуки в воде. Посадка с берега, плавание, высадка заканчивает ход — лодка остаётся у берега.
- ИИ спускается в подземелье, когда там есть что разведать, и садится в лодку, когда своя суша обобрана.

## Что нового в v1.5 «Бой»
- **Двухгексовые существа**: 38 существ из 112 занимают два гекса — переписаны занятость поля, достижимость, позиции атаки, дыхание, ров и весь ИИ боя.
- **Фаза тактики**: навык «Тактика» даёт полосу шириной в разницу уровней навыка у сторон; отряды переставляются до первого раунда.
- **Боевые машины**: баллиста, палатка первой помощи, повозка с боеприпасами — покупаются в Кузнице, выходят с героем в бой, их можно уничтожить. Плюс навыки Артиллерия, Баллистика, Первая помощь (катапульта теперь тоже зависит от навыка).
- **Способности второго эшелона**: Архангел воскрешает, Владыка бездны поднимает демонов, Мастер-джинн и Огр-маг колдуют, Фамильяр перехватывает ману.
- **Магия 5 уровня**: Армагеддон, Внедрение, Молния титанов, Берсерк; Гильдия магов V у Оплота, Башни, Некрополиса и Подземелья.

## Что нового в v1.1
- **ИИ боя считает размен**: оценивает входящий урон на клетке назначения, уводит зажатых стрелков, ждёт. Выигрывает у прежнего жадного ИИ 60 % боёв на армиях 2-й недели и 80 % — на 4-й.
- **Автотайлинг ландшафта**: типы местности наползают друг на друга по маске из 8 соседей, у берега — пена. Зоны карты получили пятна вторичной местности, дороги перестали быть лесенкой из квадратов.
- **Процедурная анимация**: существа дышат, качаются при ходьбе, замахиваются и оседают при гибели; летающие парят. Спрайты остались статичными — движение даёт деформация при отрисовке.
- **Свет**: запечённые пятна света и тени, тень под скалами, свечение лавы, мягкий туман войны и свет времени суток — неделя проживается от раннего утра к закату.

## Что реализовано (v1.0)
- Генератор карт по зонам (S/M/L, сид), два слоя (поверхность и подземелье), море с побережьем, 10 типов местности, дороги, стражи-«ворота», 40 типов объектов.
- 8 фракций × 14 существ (112) со статами оригинала и способностями (стрелки, полёт, двойной удар, без ответа, дыхание, жизнекрад, окаменение и др.).
- Города: 4 уровня ратуши, Форт/Цитадель/Замок, таверна, рынок, кузница, хранилище, гильдия магов 1–4, жилища 1–7 с улучшениями, найм, апгрейд, гарнизон.
- Герои: 16 классов, 32 именованных героя, 4 первичных и 21 вторичный навык, специальности, артефакты (36, 11 слотов), книга заклинаний (29 заклинаний, 4 школы, 3 уровня мастерства), Городской портал.
- Бой: порядок по скорости, ждать/защита, ответный удар, мораль и удача, формула урона HoMM3, заклинания, осада (стены, ворота, ров, башни, катапульта), автобой, отступление, сдача, подсказка урона до удара.
- Дипломатия стражей (присоединение / плата / бегство / бой), некромантия, банки существ, левел-апы с выбором навыков.
- ИИ противников: стройка по приоритетам, найм, несколько героев, цели по полезности, оценка опасности, разведка, осады, капитуляция.
- 4 уровня сложности, сохранения (3 слота + автосохранение, экспорт/импорт), процедурный звук, поддержка мыши и тача.

## Разработка
```
node test/run.js          # тесты правил (гексы, урон, путь, генерация, бой, сейв)
node dev/sim.js S 1 1 60  # партия ИИ против ИИ без экрана
node dev/balance.js 2 60  # win-rate фракций
node dev/mapdump.js M 7 2 # ASCII-карта
node dev/play.js 3        # сценарный прогон в браузере со скриншотами (Playwright)
node dev/saveload.js      # проверка «выход → продолжить»
node dev/aivs.js          # новый ИИ боя против прежнего жадного
node dev/aitune.js        # вклад каждого компонента ИИ боя
node dev/terrainshot.js 7 out.png L 3   # крупный скриншот ландшафта
node dev/bigshot.js       # бой с двухгексовыми существами
node dev/tacticsshot.js   # фаза тактики (с настоящими кликами)
node dev/machineshot.js   # боевые машины в бою
node dev/undershot.js     # спуск в подземелье через врата
node dev/seashot.js       # посадка в лодку, плавание, высадка
```
Структура: `js/data` — таблицы контента, `js/model` — правила/движок (без DOM, тестируется в node), `js/view` — рендер и экраны, `js/main.js` — машина экранов.

## Отклонения от оригинала (сознательно, см. ТЗ §2)
Нет Грааля, фракции Conflux, сетевой игры; в подземелье нет своих городов, в море — водоворотов и маяков. Крупные существа не разворачиваются: сторона задаёт направление на весь бой. У школы Воды нет заклинаний 5 уровня (в оригинале это Клон, Хождение по воде и Призыв элементаля — им нужны системы, которых пока нет). Стоимость улучшения жилищ и содержимое гильдий упрощены. Все ассеты нарисованы заново.
