# Гайд по пиксель-спрайтам (для всех художников проекта)

## Формат
Спрайт — JS-объект, зарегистрированный в `H3.Sprites`:
```js
(function () {
  H3.Sprites.defineMany({
    pikeman: {                     // имя = id из js/data/creatures.js
      pal: { e: '#a8b0bc' },       // необязательно: переопределить буквы палитры для этого спрайта
      rows: [                      // строки ОДИНАКОВОЙ длины; '.' — прозрачный пиксель
        '.......kk.......',
        // ...
      ],
    },
    halberdier: { base: 'pikeman', tint: { b: 'r', B: 'R' }, extra: [[13, 3, 'y'], [13, 4, 'y']] },
    //  ^ улучшенная версия: перекраска букв базового спрайта (+ extra: точечные пиксели [x, y, 'буква'])
  });
})();
```
Файл начинается с комментария-шапки, весь код — внутри IIFE, никаких `import/export`. Подключается обычным `<script>` после `js/view/sprites.js`.

## Размеры и якорь
- Существа уровней 1–4: **ширина 18–24, высота 20–24**. Уровни 5–6: до 28×28. Уровень 7: до 32×32. Не больше.
- Якорь по умолчанию — **низ по центру** (ноги стоят на нижней строке). Оставь 0 пустых строк снизу: нижняя строка — это земля. Тень под ногами не рисуй (её рисует движок).
- Все существа **смотрят вправо** (движок зеркалит для защитника). Оружие — в правой (передней) руке.
- Объекты карты (шахты, жилища, деревья): ширина ≤ 32 (банки существ ≤ 48), якорь низ-центр; здания стоят на нижней строке.

## Стиль
1. **Читаемый силуэт** важнее деталей: спрайт должен узнаваться в масштабе 1× (24 px) на карте и 2× в бою. Проверь, что два соседних уровня фракции различаются формой, а не только цветом.
2. **Контур `k`** по внешнему краю (сплошной, 1 px) — обязательно. Внутренние линии — более тёмным оттенком, не чёрным.
3. **Три тона** на материал: свет / основной / тень. Свет сверху-слева. Никакого градиента из 6 оттенков.
4. **Один акцент** — то, что делает существо им: копьё, лук, крылья, рога, посох, хвост дракона. Акцент должен выделяться цветом.
5. **Улучшенные версии**: перекраска 2–3 букв (`tint`) + 3–10 пикселей деталей через `extra` (корона, перо, свечение, второе крыло) — или полный редрав, если силуэт должен измениться (например, Гигант → Титан с молнией).
6. Летающие — с крыльями, слегка над землёй (можно оставить 1–2 пустых нижних строки только у них). Стрелки — с луком/жезлом, повёрнутым вправо. Крупные звери — четыре лапы, длинное тело.
7. Пропорции — «чиби-героические»: голова ≈ 1/3 роста для гуманоидов, большие глаза 1–2 px, ноги короткие.
8. Не пиши имя/номер внутри спрайта, не рисуй рамок.

## Как проверять (обязательно, до сдачи)
1. Сохрани файл, например `js/view/sprites_castle.js`.
2. Отрисуй лист спрайтов в PNG (Playwright уже установлен):
   ```
   cd /home/user/research/games/homm3
   node dev/shot.js "dev/sheet.html?files=view/sprites_castle.js&scale=4&cols=7" /tmp/claude-0/-home-user/a99ab51d-4089-5bf8-9571-78bcca32901c/scratchpad/sheet_castle.png 1100 700
   ```
   Параметры sheet.html: `files` — список файлов через запятую (относительно `js/`), `scale`, `cols`, `filter` — префикс имён, `names` — явный список имён через запятую.
3. Открой PNG инструментом Read и **посмотри глазами**: читается ли силуэт, нет ли розовых квадратов-заглушек (значит, спрайт не найден или ошибка), не съехали ли строки (все строки одной длины!). Скрипт печатает ошибки консоли страницы — их быть не должно.
4. Правь и повторяй, пока каждый спрайт не станет узнаваемым. Минимум два цикла проверки.
5. Проверь, что файл синтаксически корректен: `node -e "global.window=global;global.H3={Sprites:{defineMany(o){console.log(Object.keys(o).length,'sprites')}}};require('./js/view/sprites_castle.js')"` — должно напечатать число спрайтов.
