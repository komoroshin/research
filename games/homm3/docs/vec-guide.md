# Рисованный конвейер: как рисовать существ и объекты

С v3.18 графика переводится с пиксельной сетки на кривые. Этот документ — всё, что нужно, чтобы нарисовать существо (или объект) так, чтобы оно встало в игру и выглядело в одном стиле с Замком.

**Образец качества** — `js/view/vec_castle.js` и `js/view/vec_pilot.js` (мечник, грифон, медведь). Прежде чем рисовать, открой их и посмотри лист:

```
node dev/vecshot.js sheet /tmp/castle.png pikeman,archer,griffin,swordsman,monk,cavalier,angel 5
```

## 1. Файлы и правила

- Каждая фракция — свой файл `js/view/vec_<фракция>.js` (заготовки уже подключены в `index.html`).
- Движок — `js/view/vector.js`, набор деталей — `js/view/vec_kit.js`. **Их не правь**: над конвейером работают параллельно. Нужен новый помощник — напиши его в своём файле; если он полезен всем, опиши в отчёте, я перенесу в набор.
- Рисованное существо включается, только если для него есть `V.def(имя, …)` и в настройках включены рисованные существа (`?vec=1`). Без описания игра берёт старый пиксельный спрайт.
- Имя = id существа из `js/data/creatures.js` (или имя спрайта: `hero_knight`, `town_castle`, `mine_gold`…).

## 2. Описание

```js
V.def('pikeman', { w, h, anchor: [x, y], parts: [ { kind, side, pivot: [x, y], shapes: [...] }, ... ] });
```

- **Единицы — дизайн-единицы: 10 на клетку старого пиксельного спрайта.** Рамку старого спрайта даёт `K.frameOf(имя)` → `{ w, h, anchor }`. Существо должно стоять ногами в `anchor` и быть примерно той же высоты, что старое, — тогда оно займёт тот же гекс. Холст сам расширится, если крыло или копьё выходят за рамку.
- **Смотрит вправо.** Сторона защиты в бою рисуется зеркально.
- **Части = порядок слоёв** (первая рисуется первой, то есть дальше всех):
  дальнее крыло → дальние ноги → ближние ноги → корпус → голова → оружие/ближнее крыло.
  Ближние ноги кладут *до* корпуса, чтобы корпус закрыл их верх — иначе нога выглядит приклеенной.
- `kind` задаёт анимацию: `leg` — шагает (нужен `side`: −1 левая на экране, 1 правая; у четвероногих диагонали в одной фазе), `torso` — дышит и подаётся на ударе, `head` — кивает, `prop` — оружие замахивается, а у летунов (`flyer` в данных) все `prop` машут как крылья. `pivot` — точка крепления части (плечо, бедро, шея).
- Крылья летуна — `prop` с `pivot` в плече. Оружие — `prop` с `pivot` в плече руки.

## 3. Форма

```js
{ p: [[x, y], [x, y, 1], ...],  // контур через точки, сглаживается; [x, y, 1] — острый угол
  e: [cx, cy, rx, ry],          // или эллипс
  c: '#b8322c',                 // один базовый цвет — свет, тень, блик и контур посчитаются сами
  m: 'cloth',                   // материал: steel gold cloth leather skin fur feather mail wood horn gem flat
  sub: [ ...формы ],            // формы внутри (обрезаются по родителю): крест на щите, пятно на шкуре
  lines: [{ p, w, a, light, c }],// штрихи: шов, складка, прядь; light: true — светлый штрих
  glint: [[x, y, r]],           // блики: глаз, металл, камень
  flow, furLen, dens, texSize,  // направление и размер фактуры меха/перьев
  belly: 0.4,                   // мягкое затенение низа формы
  line: 0.6, lc,                // толщина контура (0 — без), цвет контура
  gloss, rim, ao, hi, lo, id }  // сила блика, контрового света, тени; id — чтобы улучшение могло убрать форму
```

Материалы: `steel` (блестит), `gold`, `mail` (кольчуга), `cloth`, `leather`, `skin`, `fur` (штрихи меха по `flow`), `feather` (перья чешуйками), `wood` (волокна), `horn` (рог, коготь, клюв), `gem` (глаз, кристалл), `flat` (без объёма). Цвет `'$b:#2050c0'` — цвет игрока (подставляется при рисовании героя), после двоеточия — запасной.

## 4. Набор деталей (`H3.VK`, в файле — `K`)

- `tube([[x, y, толщина], ...], { flat0, flat1 })` — **главный примитив**: осевая линия с толщиной → контур. Руки, ноги, шеи, хвосты, щупальца, змеиные тела, древки, рога.
- `leaf(B, ang, len, wid, T)` — перо/лист/лепесток/коготь-лезвие.
- `ell(cx, cy, rx, ry, n, a)` — эллипс точками (можно повернуть `a`), `move / grow / rot / flipX` — преобразования точек.
- `weapon.sword / polearm(kind: spear pike halberd trident lance glaive) / axe / mace / staff(orb, crook) / bow / crossbow / gun` — в кисть `hand` по направлению `dir`.
- `shield.heater / round`.
- **Гуманоид** — `humanoid({ name, legs, back, body, head, arm, before, extra, robe, size, dx })`. Рисуешь в каноне: рамка 200×250, земля y=246, ключевые точки в `K.H` (голова `headX, headY, headR`, плечи `frontSh/backSh, shY`, пояс `waistY`, таз `hipY`, бёдра `frontHip/backHip`). `humanoid` сама впишет его в рамку старого спрайта.
  - `leg(hip, foot, { style: 'armor'|'hose'|'bare', c, boot, tw, toe })`, `arm(плечо, локоть, кисть, { c, hand, m, w })`,
  - `head(cx, cy, r, { skin, hair, hairStyle: short|long|bald|none, beard, eye })`, уборы `helm.kettle / great / hood / crown / halo`,
  - `torso({ c, skirt, skirtLen, plate, belt, chestLines })`, `robe({ c, belt })` (с `robe: true` ноги скрыты).
  - Не похож на человека (орк, огр, ящер, минотавр)? Тот же `humanoid`, но свои формы в `head`/`body`, другие `tw` ног и цвет кожи.
- **Конь** — `horse({ coat, mane, hoof, barding, saddle, chanfron, horn })` → `{ legs, body, head }` в рамке 330×290 (земля y=282); `horseCreature(o)` — конь как существо (единорог, кошмар); `mounted({ name, horse, leg, back, body, head, arm })` — всадник (кавалерист, всадник на волке — подменив части коня).
- **Крылья** — `wing.feather(O, d, L, цвета)` (птица, ангел, грифон), `wing.bat(O, d, L, { mem, bone })` (дракон, демон, мантикора, виверна), `wing.insect(O, d, L, { mem, vein })` (фея, стрекоза, оса). `O` — плечо, `d` — направление кости, `L` — длина.
- `fit(parts, { ground }, frameOf(name))` — вписать свои части из любой удобной рамки в рамку старого спрайта.

Для зверей (волк, кошка, ящер, жук, змей, дракон, гидра) готовой сборки нет: собирай из `tube` (ноги, хвост, шея), сглаженного контура корпуса и головы. Смотри медведя и грифона в `vec_pilot.js` — там весь приём.

## 5. Улучшение

Либо функция с параметрами (как `pikeman(name, o)` в `vec_castle.js`) — лучше, если меняется оружие или форма; либо

```js
V.def('crusader', { base: 'swordsman', recolor: { '#a8262a': '#e8e2d2' }, add: [{ part: 3, shapes: [...] }], drop: ['id-формы'] });
```

Улучшенное должно отличаться с первого взгляда: другая гамма, плюс деталь (корона, рога, доспех, пламя, второй хвост).

## 6. Стиль

- Насыщенно, но не кислотно; тени сами уходят в холодное, свет в тёплое.
- **Силуэт важнее деталей**: в бою на телефоне существо — 60–90 точек. Семь существ фракции различаются силуэтом и цветом, а не мелочами.
- Цвета фракции общие (Инферно — красное/чёрное/огонь, Некрополис — кость/тёмно-зелёное/фиолет, Подземелье — пурпур/серое, Оплот — зелень/золото и т. д.) — смотри старые спрайты и `js/view/townscene.js` (`TINT`).
- Опирайся на старый спрайт: та же идея существа, поза, цвета — только нарисовано по-настоящему.
- Не больше ~150 форм на существо (скорость первой отрисовки на телефоне).

## 7. Проверка (обязательно, до сдачи)

1. `node --check js/view/vec_<фракция>.js`
2. Лист: `node dev/vecshot.js sheet /tmp/f.png имя1,имя2,... 5` — смотри глазами: старый / новый / бой свой и чужой / кадры. Проверь: смотрит вправо; ноги на линии земли; при шаге и замахе части не расходятся и не вращаются вокруг чужой точки; в размере боя существо читается.
3. Крупно — сам нарисуй через `H3.Vec.render(имя, 14)` в странице `index.html?dev=1&vec=1` (пример — `dev/vecshot.js`).
4. Бой: `node dev/vecshot.js battle /tmp/b <атака> <защита> [местность]` → `_l.png`, `_r.png`, `_zoom.png`. Крупные (`large`) — 2 гекса, не должны налезать на соседние ряды сильнее старых.
5. `node test/run.js` — все зелёные.
