# Бэктест: арбитраж BESS на day-ahead OMIE (Испания)

Данные: OMIE marginalpdbc, 2025-01-01 — 2026-09-04 (610 дней; часовые до 30.09.2025, 15-мин с 01.10.2025; отсутствуют 2025-10-30 и 2025-11-27 — файлы OMIE недоступны, HTTP 404). Источник: https://www.omie.es/es/file-access-list (обращение 2026-09-05).

Стратегии: naive — фиксированные окна 12–16/19–23; persist — MILP на ценах дня D-1 (простое правило, доступно любому representante); realistic — MILP на прогнозе D-1 (бустинг); perfect — MILP на факте (верхняя граница). Аннуализация каждой колонки — по её доступным дням (realistic — с 2025-04).

Батарея: 10 МВт / 20 МВтч, КПД 88 %, ≤ 1.5 цикла/день, штраф деградации 0.5 €/МВтч (допущение). Только day-ahead, без intraday и балансирующих рынков (нет токена ESIOS).

## Солвер (HiGHS через scipy.optimize.milp, бинарные режимы заряд/разряд)

- 96 интервалов × 1 рынок: 15 мс; 192 интервала (48 ч): 29 мс; прокси 3 рынка × 48 ч (576 интервалов): 152 мс. Полный прогон бэктеста: 13.0 мин.

## Ограничения и допущения

- Только day-ahead: нет intraday (SIDC), aFRR/mFRR, механизма мощности — реальный стек выше.
- Погода — реанализ, а не прогноз D-1 (утечка в пользу realistic; допущение ≈ 1–3 п.п.).
- Дневная оптимизация, SoC 0 в начале дня, остаток не переносится (консервативно для perfect на 1–2 %).
- Наивная стратегия — фиксированные окна 12–16 / 19–23 (по брифу), она реалистична для «EMS без оптимизатора» лишь частично.
- Прогноз обучен с 2025-01, первые прогнозы с 2025-04; 15-мин истории < 1 года.
