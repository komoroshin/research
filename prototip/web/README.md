# Веб-прототип — один файл

`threshold-prototype.html` — кликабельный прототип уровня A без зависимостей:
все экраны, логика переходов по `../01-specifikaciya.md`, переключатель
момента (пять быстрых нажатий на верхнюю строку любого экрана или панель
слева на широком экране), EN/RU.

- На макбуке: открыть файл в браузере — рамка телефона 390×844 и панель
  моментов слева.
- На айфоне: открыть в Safari → Поделиться → «На экран Домой» — запускается
  на весь экран, без адресной строки. Работает офлайн; Google Fonts
  подхватываются при сети, без неё — системные шрифты.
- По ссылке: опубликован как страница claude.ai (см. чат), тот же файл без
  обёртки документа.

Ограничения уровня A: Health — демо-числа с пометкой; распознавание еды —
выбор из пяти блюд; уведомлений нет. Вердикт после проверки фруктанов
показывает заготовку про молоко — данные заготовлены на одну группу.

Проверено headless-прогоном: 18 состояний основного оборота, ошибок JS нет
(скриншоты в отчёте сессии).
