# Веб-прототип — один файл (версия 2)

`threshold-prototype.html` — кликабельный прототип уровня A без зависимостей:
все экраны, логика переходов по `../01-specifikaciya.md`, переключатель
момента скрытый, как в спецификации: пять быстрых нажатий на верхнюю строку
любого экрана (там же смена EN/RU и сброс на день 0). На экране у
пользователя никаких служебных элементов нет.

- Опубликован: https://komoroshin.github.io/research/prototype/ — язык
  берётся из настроек телефона (русский → RU, остальное → EN).
  Русская версия принудительно: https://komoroshin.github.io/research/prototype/ru/
  (файл `threshold-prototype-ru.html` — та же сборка с метатегом языка;
  также работает `?lang=ru` / `?lang=en`). На main лежат копии
  `prototype/index.html` и `prototype/ru/index.html`; обновлять тем же путём,
  что деку — через worktree на main, только эти файлы.
- На макбуке: открыть файл в браузере — рамка телефона 390×844.
- Как идти по дням: «Закрыть день» переводит на следующий день. Вывод про
  сон приходит на 7-й день, подозрение — когда набраны минимумы (20 полных,
  10 плохих, 10 хороших дней, в заготовленной истории это 21-й день),
  «не сейчас» возвращает подозрение через три дня, проверка идёт 8 закрытий
  дня. Переключатель момента нужен только для перемотки на показе.
- На айфоне: открыть в Safari → Поделиться → «На экран Домой» — запускается
  на весь экран, без адресной строки. Работает офлайн; Google Fonts
  подхватываются при сети, без неё — системные шрифты.
- По ссылке: опубликован как страница claude.ai (см. чат), тот же файл без
  обёртки документа.

Ограничения уровня A: Health — демо-числа с пометкой; распознавание еды —
выбор из пяти блюд; уведомлений нет. Вердикт после проверки фруктанов
показывает заготовку про молоко — данные заготовлены на одну группу.

Проверено headless-прогоном: 18 состояний основного оборота, ошибок JS нет
(скриншоты в отчёте сессии).

## Версия 2

Собрана по `../06-ux-issledovanie.md` и `../07-tz-v2.md`: три вкладки
«Сегодня · Путь · Советы», еда на главном (плитка фото и «Недавнее» одним
тапом), карта дня со шкалами 0–10 с подписями значений и типами Бристоля,
карточка фона с источником, «Путь» с узлами этапов и картой переносимости,
красный флаг с подтверждением и снимаемой паузой, план проверки и
раскрываемые замены, вариант «Ритм» (включается в скрытой перемотке).
Первая версия сохранена как `threshold-prototype-v1.html`.

## Версия 3 — по дизайн-системе Threshold

Источник: `../design-system/` (пакет Threshold Design System, собран из версии 2
прототипа). Что изменилось:

- **Взвешивание палитры B3.** Насыщенный зелёный остался только там, где можно
  действовать: кнопки, выбранные ячейки, линейки, текущий день, ссылки-действия.
  Крупные поверхности перешли на интерфейсный ряд пониженной насыщенности
  (`--paper-warm`, `--pine`), заголовки — ink-700 вместо forest.
- **Второй тон — пыльно-синий.** Единственная холодная краска в системе и ровно
  одна работа: «на это есть ответ». Порог, распознанное блюдо, пройденные дни
  проверки, точки пути, отвеченная группа в карте.
- **Лента дня вместо блока еды.** Полоса 06:00–24:00 с отметкой на каждом приёме
  пищи и горизонтальные плитки: время в Oswald, блюдо, группы. Последняя плитка —
  тёмная «Добавить». Фото не хранятся: снимок распознаётся и удаляется.
- **Карточка для ресторана** — новый экран из «Пути»: карта переносимости, сказанная
  вслух, на языке кухни. Никаких запрещающих знаков, максимум «прошу без этого».
- **Страница для врача** — документ: участник, период, версия протокола, исключённые
  дни с причиной и явный отрицательный ответ по красным флагам.
- Уведомление ушло под верхнюю строку, `--text-unit` для суффиксов у чисел,
  вторичное начертание Oswald 500 для заголовков под заголовком.
