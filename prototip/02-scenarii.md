# Пользовательские сценарии прототипа

Каждый сценарий — последовательность «человек делает → видит → результат».
Ссылки на экраны — по спецификации, ключи текстов — по `04-teksty.md`.
Сценарии S1–S3 — обязательные для приёмки, S4–S9 — альтернативные ветки,
D1 — демо для стенда, T — самопрогон.

## S1. Первый запуск и первый день

1. Открывает приложение впервые → Э0: заголовок «Первые дни мы ничего не
   запрещаем — мы смотрим», три вопроса.
2. Отвечает на три вопроса сегментами → ничего не блокируется, ответы
   можно не менять.
3. Нажимает «Разрешить Health» → системный диалог → разрешает.
   Альтернатива: отклоняет → продолжение без блокировки.
4. Нажимает «Начать» → Today в моменте day0: карточка «Сегодня вечером —
   первая карта дня», кнопка «Закрыть день» неактивна до вечера
   (в прототипе — активна всегда).
5. Вечером нажимает «Закрыть день» → Э1: три ползунка, строка фона со сном
   из Health (или демо с пометкой).
6. Двигает ползунки, нажимает «Закрыть день» → Today с подтверждением
   «День записан. Первый вывод — через 6 дней».

**Результат.** Человек понял, что от него требуется 30 секунд вечером и
никаких запретов.

## S2. Седьмой день — первый вывод

1. Момент day7 → Today показывает карточку Э2: «В четырёх из пяти плохих
   дней ночь была короче шести часов. Пока это наблюдение, не вывод».
2. Нажимает «Понятно» → карточка сворачивается в строку «Наблюдение от
   7 сентября» под счётчиком уверенности.

**Результат.** Обещанный день выдачи наступил, вывод настоящий, но
честно назван наблюдением.

## S3. Основной оборот: подозрение → проверка → ответ

1. Момент suspicion → поверх Today открывается Э4: «В 12 из 15 ваших
   плохих дней было молочное. В хороших днях — в 3 из 20. Это может
   оказаться совпадением…» и три равные кнопки.
2. Нажимает «Проверим» → Э5 в моменте check1: шапка «Проверка: молочное ·
   день 1 · без молочного», карточка задачи, три замены «из вашего
   рациона», шкала дней.
3. Переключатель момента → check3: третий день, два пройденных.
4. Нажимает «Закрыть день» → Э1 → закрывает → возвращается в Э5 со
   строкой «День 3 засчитан».
5. Переключатель → check6discarded: карточка «Сегодня без пробы. Ночь
   4 ч 40 мин…», доза переносится, шкала показывает отбракованный день
   отдельной меткой.
6. Переключатель → verdict: Э6 «Молоко: до 125 мл переносится, 250 мл
   даёт симптомы», подпись про личный разброс и контрольный день, кнопка
   «Следующий подозреваемый: фруктаны».
7. Нажимает ссылку «В карту» → Э7: лактоза с порогом, пять групп «в
   наблюдении».

**Результат.** Человек прошёл круг и увидел ответ в форме «сколько», а не
«нельзя».

## S4. «Не сейчас»

1. Э4 → нажимает «Не сейчас» → возврат в Э3 с тостом «Вернёмся с этим
   позже. Наблюдение продолжается».
2. Счётчик уверенности на месте, ничего не потеряно.

**Результат.** Отказ — не провал; приложение не давит.

## S5. Другой подозреваемый

1. Э4 → «Другой подозреваемый» → список: «Фруктаны — в 9 из 15 плохих
   дней, в 5 из 20 хороших» (слабее).
2. Выбирает → Э4 с фруктанами и теми же тремя кнопками.

**Результат.** Человек видит, что подозреваемых может быть несколько, и
выбирает, с чего начать.

## S6. Пропущенный день в проверке

1. Момент check3 с флагом «вчера без записей» → Э5 показывает карточку
   «Вчера без записей. Проверка на паузе, не провалена. Продолжим
   сегодня» вместо задачи.
2. Нажимает «Продолжить» → задача дня.

**Результат.** Пропуск приостанавливает, а не сбрасывает.

## S7. «Не подтвердилось»

1. Момент verdictNotConfirmed → Э6: «Не подтвердилось: разница в пределах
   вашего обычного разброса. Молочное можно вернуть» — нейтральный цвет,
   не ошибка.
2. Кнопка «Следующий подозреваемый».
3. В Э7 лактоза помечена «проверено: переносится».

**Результат.** Снятое ограничение подано как результат, а не провал.

## S8. Красный флаг

1. В Э1 включает переключатель «кровь в стуле» → немедленно Э8: «Протокол
   на паузе. Вы отметили кровь в стуле. Это может быть серьёзнее СРК.
   Обратитесь к врачу — вот что ему показать».
2. Единственная кнопка → Э7а страница для врача.
3. Назад в Today пути нет; выход — только через переключатель момента.

**Результат.** Остановка без интерпретации; продолжить нельзя.

## S9. Страница для врача и шаринг

1. Э7 → «Страница для врача» → Э7а: протокол, результаты по группам,
   динамика самочувствия, подвал «наблюдения участника, не диагноз».
2. Нажимает «Поделиться» → системный share sheet с текстом страницы.

**Результат.** Артефакт, который можно унести к врачу.

## D1. Демо для стенда — 90 секунд

Показывающий держит телефон, зритель смотрит. Порядок фиксированный:

| Сек | Момент | Что говорит показывающий |
|---|---|---|
| 0–10 | Э3 background | «Месяц человек просто живёт и вечером отвечает на три вопроса. Приложение копит» |
| 10–30 | Э4 suspicion | «И вот оно нашло: в 12 из 15 плохих дней было молочное. Оно не запрещает — предлагает проверить. Можно сказать „не сейчас“» |
| 30–50 | Э5 check3 → check6discarded | «Проверка — восемь дней одной группы. Смотрите: короткая ночь — день не засчитан, доза переносится. Трекер бы этого не заметил» |
| 50–70 | Э6 verdict | «Ответ — одна строка: до 125 мл переносится, 250 даёт симптомы. Не „нельзя“, а „сколько“» |
| 70–90 | Э7 map → Э7а | «Из таких ответов складывается карта. И страница для врача» |

Переключатель момента — единственное, что нажимает показывающий между
экранами. Э8 показывать только по вопросу «а если что-то серьёзное?».

## T. Самопрогон команды — выходные

Каждый проходит на своём телефоне, отмечает по каждому пункту «ок» или
что не так. Правка — только если мешает пройти сценарий.

- [ ] S1 целиком, с Health разрешённым
- [ ] S1 с Health отклонённым — есть пометка «демо-данные»
- [ ] S3 целиком через переключатель момента
- [ ] S4, S5 — кнопки Э4 работают все три
- [ ] S6 — пауза показывается и снимается
- [ ] S7 — «не подтвердилось» не выглядит ошибкой
- [ ] S8 — из Э8 нет пути назад
- [ ] S9 — share sheet открывается с текстом
- [ ] D1 — 90 секунд проходятся без единого экрана, которого нет
- [ ] Переключение языка — все экраны на RU и на EN, без пустых строк
- [ ] Грep по файлу строк: нет слов «нельзя», «уберите», «диагноз», «лечит»,
      «вы пропустили»
