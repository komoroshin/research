Oswald uppercase headline — the brand's voice at heading scale; `answer` (34px) is reserved for the one line that carries the product's payoff.

```jsx
<Display size="answer">Milk: up to 125 ml is fine, 250 ml brings symptoms</Display>
<Display size="hero" dark>Eat as usual</Display>
```

Sizes: answer 34, screen 26, hero 24, card 22, inline 20, tile 18. `weight="secondary"` drops to Oswald 500 — use it when a heading sits under another heading, instead of dropping a size step. Always uppercase, always tracked -0.02em; pair with a `Rule` beneath for screen titles.
