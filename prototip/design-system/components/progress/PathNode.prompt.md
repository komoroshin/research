A stage in the observation → suspect → test → answer timeline on the Path tab.

```jsx
<PathNode title="Observing" meta="day 14 of ~21" state="current">
  <ProgressBar value={66} />
</PathNode>
<PathNode title="First insight" meta="Sep 7" state="done" />
<PathNode title="Test 1 · dairy" meta="when the data is in" state="ahead" last />
```

Ahead nodes are outline-only with sage-500 text; the current node's pin carries a 4px sage-100 halo.
