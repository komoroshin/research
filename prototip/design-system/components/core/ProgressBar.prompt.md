8px forest-on-cream bar for observation progress (days collected out of ~21) — the only bar in the product.

```jsx
<ProgressBar value={66} />
<BodyText tone="soft" size="xs">about 7 more days to a suspect</BodyText>
```

Never label it with a percentage of "completion" and never animate it triumphantly; progress in Threshold is a count of days, nothing more.
