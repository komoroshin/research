# Экраны прототипа — исходники канвы

Артборды дизайн-канвы «Threshold Prototype Screens»
(https://claude.ai/code/artifact/e45a9ab0-fb6b-4e7a-b117-2c33e4cf1d30).
Собраны по `../03-tz-dizajn.md` из токенов дизайн-системы Threshold
(Forest & Sage, Oswald + Inter, зерно, карточки 24, кнопки 20) и
текстов `../04-teksty.md` (английский).

`gen.py` генерирует все `*.dc.html`; правки — в нём, потом перегенерация
и пересборка канвы. `canvas.json` — раскладка: четыре ряда по этапам
оборота.

Экстраполяции, которых в дизайн-системе нет (там нет контролов вообще):
сегментные переключатели, ползунки 0–5, переключатели-тумблеры, шкала
дней проверки, таб-бар. Собраны из палитры и радиусов системы по её же
правилу для кнопок. Красного в системе нет — экран красного флага сделан
единственным полностью тёмным.
