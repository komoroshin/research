# Прототип Threshold, уровень A — производственный пакет

Пакет документов для сборки кликабельного прототипа одного оборота:
подозрение → проверка → ответ. Родительские документы — `../prototip-brif.md`
(решения фаундера, история Анны, три уровня) и `../mashina-gipotez-spec.md`
(параметры машины и правило адаптивной длины).

| Файл | Кому | Что |
|---|---|---|
| `01-specifikaciya.md` | CTO | границы, модель данных, навигация, каждый экран с элементами, состояниями, переходами; Health; правила, которые нельзя нарушить |
| `02-scenarii.md` | CTO, команда | S1–S9 пользовательские сценарии, D1 демо для стенда на 90 секунд, T чек-лист самопрогона |
| `03-tz-dizajn.md` | Клод Дизайн | задание на экраны: принципы, каждый экран, что сдать, чего не делать |
| `04-teksty.md` | все | единый источник строк RU/EN по ключам — файл локализации |
| `05-priemka.md` | фаундер, CTO | критерии «готово», что сдаётся в понедельник |

Порядок работы: тексты фиксированы первыми (они — контент), дизайн и
код идут параллельно от одних ключей, приёмка — по сценариям, не по
экранам.
