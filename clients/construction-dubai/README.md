# Строительный клиент: Дубай / Армения / гидроизоляция

Диагностика бизнеса и поиск точек, где ИИ и автоматизация дают деньги или снимают нагрузку с владельца.

## Что знаем на старте
- **Дубай**: глубокая реновация вилл. Ядро бизнеса и основной источник денег.
- **Армения**: новое направление, строительство. Главная проблема, вероятно, в удалённом контроле.
- **Гидроизоляция**: свой продукт. Другая модель (производство, B2B-продажи, дилеры).
- Всё держится на владельце, цифр почти нет. Запрос звучит как «не хватает автоматизации».

## Главный тезис
Автоматизировать хаос бессмысленно. Порядок работы: **диагностика → минимальный учёт (цифры) → 2–3 быстрые победы → пилот с замером → масштабирование**.
Фокус первого этапа только на Дубае.

## План

| Этап | Срок | Результат |
|---|---|---|
| 0. Рамка | 1 встреча | Цель в цифрах, формат, доступы, NDA |
| 1. Диагностика | 2–3 недели | Карта процесса, список болей с оценкой в деньгах/часах |
| 2. Цифры | параллельно | Реестр 10–20 последних проектов с маржой |
| 3. Выбор побед | 1 встреча | 2–3 инициативы из бэклога |
| 4. Пилот | 4–6 недель | Работающее решение + замер «до/после» |
| 5. Масштаб | дальше | Армения (контроль), гидроизоляция (продажи) |
