# Aureum Quote: Telegram-бот (каркас)

Инженер отправляет боту видео обхода крыши, голосовые, фото и заметки по объекту, затем `/done`. В ответ приходит сводка, вопросы «что уточнить» и PDF черновика КП.

```
Telegram → бот → ffmpeg (звук + кадры) → расшифровка речи (API) → Claude API (кадры + фото + текст → параметры)
       → расчёт по прайсу (pricing.py) → PDF → ответ в Telegram
```

Цены считает `pricing.py`: те же правила, что в веб-прототипе `../app/index.html`. Claude только извлекает параметры.

## Модули
| Файл | Что делает |
|---|---|
| `aiquote/bot.py` | Telegram-бот: приём файлов, `/done`, `/new`, `/status`, доступ по списку `ALLOWED_USER_IDS` |
| `aiquote/pipeline.py` | Обработка одного выезда от файлов до PDF |
| `aiquote/media.py` | ffmpeg: звук из видео, равномерные кадры, моно-mp3 для распознавания. Без системного ffmpeg берёт бинарник из `imageio-ffmpeg` |
| `aiquote/transcribe.py` | Расшифровка: `openai` (gpt-4o-transcribe / whisper-1) или `sidecar` для тестов |
| `aiquote/extract.py` | Claude API: изображения + текст → JSON по схеме (structured outputs), с серверным фолбэком на случай отказа модели. `stub` для тестов |
| `aiquote/pricing.py` | Прайс и правила расчёта, НДС 5% |
| `aiquote/pdf.py` | PDF КП |
| `aiquote/cli.py` | Прогон выезда из локальных файлов без Telegram |

## Запуск на тестовых файлах (без ключей)
```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python samples/make_samples.py            # синтетическое видео, голосовое, фото
STT_PROVIDER=sidecar EXTRACTOR=stub python -m aiquote.cli \
  samples/roof_test.mp4 samples/voice_test.ogg samples/photo_test.jpg --out out/demo
pytest -q                                 # 7 тестов
```
Тестовые медиа синтетические: картинка-заглушка и тон вместо речи. Расшифровки подставляются из `samples/*.txt`, параметры — из `samples/expected_params.json`. Это проверяет конвейер целиком, но не качество распознавания.

## Запуск с настоящими сервисами
1. Бот: создать у @BotFather, токен в `.env`.
2. `cp .env.example .env` и заполнить ключи: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `ALLOWED_USER_IDS`.
3. Проверить на реальном видео без Telegram: `python -m aiquote.cli path/to/roof.mp4 --out out/real`
4. Запустить бота: `python -m aiquote.bot`

Ключи хранятся только в `.env` на сервере. `.env`, `data/` и `out/` в git не попадают.

## Ограничения каркаса
- Бот держит выезд в памяти: при перезапуске незавершённый выезд теряется.
- Telegram отдаёт боту файлы до 20 МБ. Для длинных видео нужен свой Bot API-сервер или загрузка через веб-форму.
- Нет правок КП словами в боте (есть в веб-прототипе), нет истории КП и админки прайса.
- Реальное распознавание (OpenAI) и разбор выезда (Claude) не проверялись: в этой среде нет ключей. Запрос к Claude проверен тестом на форму (модель, схема, фолбэк, порядок изображений).
- Прайс — по 10 КП начала 2025 года, зашит в `pricing.py`. Дальше его стоит вынести в таблицу, которую правит Роман.

## Следующие шаги
1. Прогнать 2–3 реальных видео с крыши через `cli`, сравнить с КП инженера, выбрать сервис расшифровки.
2. Сохранять выезды и КП (SQLite / Postgres), нумерация КП.
3. Правки КП в боте текстом и голосом, журнал правок с причиной.
4. Развернуть на сервере (VPS или контейнер) как службу.
