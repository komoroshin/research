## 1. API и доступ к системам: что открыто, что закрыто

### 1.1. TMS / ERP транзитария

| Система | Публичный API | Что реально доступно | Вывод для MVP |
|---|---|---|---|
| **Riege Scope** | **Да, REST read-only** — Order API (отгрузки, air/ocean, customs, финансы), Partner, Salesperson, Charge Type; Quotation API умеет создавать (https://riege.github.io/scope-rest-webservices/) | Единственный TMS с открытой документацией; механизм аутентификации на публичной странице не описан | Приоритетная интеграция, если клиент на Scope |
| **CargoWise (WiseTech)** | Не REST: **eAdaptor** — обмен XML (UniversalShipment, UniversalEvent) по SOAP; eAdaptor Next — OAuth2/JWT | Только для клиентов и партнёров, потранзакционная оплата | Через клиента-партнёра, не самостоятельно |
| **VisualTrans** (ES) | Заявлена «API nativa», документация закрыта; ISO 27001; свой «Asistente Virtual Aduanero» | Вендор уже продаёт ИИ по таможне — конкурент и потенциальный партнёр | Партнёрство |
| **DeiWorld, Quatuor G4, Bytemaster B-First, SC Trade Bitácora** (ES) | Публичных API нет | Bytemaster на .NET + SQL → возможен read-only доступ к БД или реплика по договору с клиентом; у остальных — экспорт CSV/XLSX/PDF и «почтовый след» | Экспорт по расписанию или партнёрство с вендором |
| **Magaya** | XML Web Service, документация за логином | В Испании присутствие не подтверждено | Не приоритет |

**Главный вывод:** полноценного API у испанских TMS нет. Для MVP данные TMS берутся через выгрузки и почту, а не через интеграцию — это снимает зависимость от вендора на старте, но ограничивает глубину.

### 1.2. Таможня
- **Taric TDua** — публичного REST нет, но есть задокументированные механизмы импорта/экспорта: 40+ форматов (H1 импорт, AES экспорт, NCTS, ENS, EXS, G3/G5, SOIVRE, счета) (https://docs.taric.es/duasql-public/index.html).
- **AEAT** — обмен XML по SOAP, обязателен сертификат пользователя FNMT; каталог WSDL/XSD опубликован (https://www3.agenciatributaria.gob.es/static_files/common/internet/dep/aduanas/ws.html).
- **ICS2** — подача через Shared Trader Portal или system-to-system интерфейс с обязательным self-conformance testing (Комиссия ЕС).
- **Для продукта: ничего не подаём в AEAT и ICS2.** Read-only архитектура снимает солидарную ответственность представителя (UCC art. 77) и требования AEO к контролю изменений.

### 1.3. PCS портов — ключевой источник событий
- **valenciaportPCS:** три способа интеграции — XML («все транзакции через одно соединение»), EDI (EDIFACT, ANSI X.12), плоские файлы. Гайды для разработчиков публичны по типам сообщений: booking IFTMBF/IFTMBC, **tracking IFTSTA**, COPARN/CODECO/COPINO, COPRAR/COARRI, VERMAS, таможня IFCSUM/CUSRES (https://www.valenciaportpcs.com/soporte/documentacion/guias-para-desarrolladores/). Стоимость интеграции с третьими лицами — **350 € разово + 45 €/мес** с согласия портовой администрации.
- **PORTIC (Barcelona):** 275 тыс. вызовов веб-сервисов в день, 7,2 тыс. подключённых пользователей, 150 тыс. сообщений в день (https://www.portic.net/); техническая документация — за входом, интеграция обсуждается напрямую.
- Algeciras, Bilbao, Puertos del Estado — не проверены.

### 1.5. Почта и документы (лимиты проверены)
- **Microsoft Graph (Outlook):** 10 000 запросов за 10 минут на пару «приложение + почтовый ящик»; общий лимит 130 000 запросов за 10 секунд на приложение (https://learn.microsoft.com/en-us/graph/throttling-limits).
- **Microsoft Graph (SharePoint/OneDrive):** 1 200 000 resource units за 24 часа и 1 250 RU/мин на тенант при 0–1 000 лицензий; delta-запрос — 1 RU, операции с правами — 5 RU.
- **Gmail API:** 1 200 000 quota units в минуту на проект, 6 000 на пользователя; `messages.get` = 20 units. Для 40 ящиков нагрузка пренебрежима.
- **WhatsApp Business (Meta Cloud API):** с 01.07.2025 потарифная оплата за сообщение, **все не-шаблонные сообщения внутри 24-часового окна обслуживания бесплатны** — то есть ответы клиенту, который написал первым, ничего не стоят.

### 1.6. Реалистичные коннекторы MVP
1. **Почта + файлы (M365 / Google Workspace)** — без партнёрств, документированные лимиты, готовые open-source коннекторы.
2. **PCS порта** — valenciaportPCS по прайсу (350 € + 45 €/мес), Portic по переговорам; структурированные события «судно — контейнер — таможенный выпуск».
3. **Трекинг-агрегатор** — Terminal49 Essential PAYG или Shipsgo ($2/контейнер, известная цена).
4. **TMS — только экспорт** (CSV/XLSX/PDF по расписанию, SQL-реплика для on-prem инсталляций).

Партнёрство с вендором потребуется для VisualTrans, DeiWorld, Quatuor, Bytemaster, SC Trade, Taric и CargoWise. Рекомендация: выбрать 1–2 вендора с наибольшей долей среди членов ATEIA-Barcelona (выясняется на интервью) и предлагать им ИИ-слой как совместное предложение.

## 4. Архитектура MVP «статус + документы + черновик котировки»

```
Источники (только чтение)
  M365 / Google: почта + SharePoint/Drive     PCS: valenciaportPCS XML (IFTSTA/COARRI/CODECO), Portic по договору
  Трекинг-агрегатор: webhooks                 TMS/TDua: экспорт CSV/XLSX/PDF по расписанию или SQL-реплика
  Тарифные таблицы: папка «rates» (Excel/PDF ставок линий и клиентских тарифов)
        │  коннекторы (MCP-серверы и воркеры), инкрементально: Graph delta, Gmail history,
        │  события PCS, webhooks; каждая запись помечена tenant_id и правами источника
        ▼
Наш кластер в ЕС (Hetzner / OVH / Scaleway / Azure EU)
  Ingestion: Docling (PDF и сканы) → нормализация → извлечение сущностей → «граф отгрузки» (Postgres)
  Индекс: Postgres + pgvector (эмбеддинги bge-m3 или Qwen3) + OpenSearch BM25
  Права: Postgres row-level security по (тенант, роль, клиент, категория «rates»)
  Оркестратор (Pydantic AI + MCP): маршрут → поиск с фильтром прав → модель → ответ
    с цитатами (источник, событие, дата) → оценка уверенности → черновик
  Модель: Sonnet 5 через Bedrock EU | gpt-5.4 EU | Mistral | vLLM с open-weight (опционально)
  Аудит-лог (только добавление): кто спросил, что найдено, что показано, что отправлено
  Оценка качества: Langfuse, DeepEval/Ragas на «золотом» наборе отгрузок
        ▼
Интерфейсы
  Веб-консоль (чат + карточка отгрузки + очередь черновиков)
  Outlook add-in / Gmail add-on: «Ответить с помощью ассистента» → черновик в окне письма
  Teams-бот (внутренние вопросы), WhatsApp Business (ответы клиенту в 24-часовом окне)
  Человек в цикле: черновик → оператор правит и одобряет → отправка из ЕГО почты
  Запрет на уровне архитектуры: никаких действий на запись в AEAT, ICS2, PCS, TMS
```

**Стек:** Python 3.12, FastAPI, Postgres 16 + pgvector с row-level security, Redis/Celery, Docling, pydifact, Pydantic AI + MCP, Langfuse, Presidio; фронт Next.js; Outlook add-in на Office.js.

**Модель поставки:** по умолчанию мультиарендный SaaS в ЕС с изоляцией схем и отдельными ключами шифрования; для AEO и крупных клиентов — single-tenant или on-prem на open-weight модели (Qwen3, Mistral Small — Apache 2.0), с учётом обязательств Cyber Resilience Act для дистрибутива.

**Роли и права:** `operativo` — отгрузки своего направления без чужих тарифов; `customer service` — только закреплённые клиенты; `aduanas` — таможенные документы без коммерческих ставок; `dirección` — всё. Ставки линий и клиентские тарифы — отдельная категория коммерческой тайны: черновик котировки видит ставки, но исходящий текст никогда не содержит ставок другого клиента.

**Аудит-лог** только на добавление, с экспортом для AEO-аудита; хранение промптов 90 дней по умолчанию, лог одобрений — 3+3 года по аналогии с таможенными документами (UCC art. 51).

## 6. Риски качества и человек в цикле

| Где ошибка недопустима | Контроль |
|---|---|
| **Неверный статус или ETA клиенту** | Ответ строится только из событий с источником и временной меткой; в черновике цитата вида «COARRI 05.09 14:10, valenciaportPCS»; обязательное одобрение человеком; «данных нет после дд.мм» вместо догадки |
| **Перепутать контейнер, коносамент или клиента** | Поиск жёстко фильтруется по `client_id` через row-level security; номера контейнеров валидируются контрольной цифрой ISO 6346; автотест на утечку между клиентами в CI |
| **Раскрыть ставки другого клиента или закупочные ставки линий** | Категория «rates» отделена; в черновик клиенту попадают только его тарифы; закупочные — во внутренней части с маркером «не отправлять»; пост-проверка исходящего текста |
| **Неверная таможенная классификация** | **Не делаем в v1** — ни классификации, ни советов по декларации; при вопросе ассистент отсылает к TariffOne/TDua и к отделу aduanas |
| **Сроки таможенных действий** | Показываем только факты из источников (MRN, Levante, дата), не считаем дедлайны |
| **Автономные действия** | Архитектурный запрет: нет коннекторов на запись; отправка только из ящика оператора после одобрения |
| **Галлюцинации по документам** | Структурированные выходы и цитаты с идентификатором документа и страницей; ответ без цитаты клиенту не показывается |
| **Дрейф после смены модели** | «Золотой» набор 200–500 вопросов по 50–100 отгрузкам партнёров; прогон DeepEval/Ragas в CI перед релизом |
| **Персональные данные в логах** | Presidio-псевдонимизация, хранение 30–90 дней |

Цена надёжности: плюс 15–25 % к стоимости разработки (слой прав, цитаты, очередь одобрений, набор для оценки) и плюс 10–20 % токенов на цитирование. Для брокерской ниши посчитано отдельно: разметка «золотого» набора 250 полисов — 15–19 k€ разово, инфраструктура оценки — $60–120 в месяц, время ревью у клиента — 0,2–0,3 FTE. Это и есть продающий аргумент для AEO-клиентов.

## 7. Кратко — запасная ниша: страховые брокеры (полностью — `raw/tech_recon_brokers.md`)

- **API систем брокера:** публичных API нет ни у segElevia (53 % рынка), ни у ebroker (16 %), ни у Gecose и iSegur; единственный задокументированный партнёрский REST — Codeoscopic «Integra» по договору. Интеграция тарификатора Avant2 с ERP — **файловая**, значит и нам путь через файлы.
- **Главная находка: EIAC/CIMA.** XSD версии 7.1 и документация **публичны и бесплатны** на cimaseg.es (пакет `XML-V07-1_V05.zip`, июль 2026); подключение к платформе CIMA — через веб-сервис TIREA по контракту, аккредитация не требуется, тарифы не публикуются; подключено 30 вендоров ПО и 39 страховщиков. **MVP может вообще не подключаться к CIMA** — достаточно парсить EIAC-файлы, которые ERP брокера уже скачал.
- **Экстранеты страховщиков:** порталов для разработчиков в Испании не найдено; отраслевой интерфейс — это EIAC/CIMA, остальное — почта. RPA вне MVP.
- **Инференс на брокера:** премиальная модель $445 → $315 в месяц с кэшем ($490/$345 при размещении в ЕС); дешёвый тир $37–230; self-hosted 70B на 2×A100 — $3 300 при одном клиенте и $330 при десяти.
- **Бюджет до первого платящего:** команда 5,8 FTE, 7–9 месяцев, **€280–445 k ≈ $325–515 k** в Испании или **€150–260 k ≈ $175–300 k** командой в СНГ.
- **Риски качества** специфичны: условия покрытия и исключения (консультационная ответственность брокера), суммы и даты окончания полиса, смешение клиентов, данные о здоровье (в v1 только No Vida).
