# Макростатистика для скрининга ниш среднего бизнеса (30–500 сотрудников): Испания, ЕС, СНГ

Дата сборки: 2026-09-06. Аналитик: research-team / market. Правило: каждое число — `значение (источник, ссылка, дата публикации)`. Всё опубликованное до сентября 2024 помечено `[>24 мес]`. Числа без источника помечены `[НЕТ ИСТОЧНИКА — не для питча]`.

Как получены данные: Eurostat — через официальный API dissemination (`ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/<dataset>`), значения сверены с Statistics Explained и новостями Eurostat; INE — через официальный JSON-API Tempus (`servicios.ine.es/wstempus/js/ES/DATOS_TABLA/<id>`) и пресс-релизы; остальное — прямое чтение страниц/PDF.

Условные обозначения размеров: Eurostat/INE считают по числу занятых (10–49 / 50–249 / 250+). Целевой сегмент продукта (30–500) не совпадает с официальными классами; ближайшая аппроксимация — «50–249» (ядро) плюс верх «20–49» и низ «250+».

1. INE, издание 2025 (I кв. 2025): таблицы «ИИ × размер предприятия» и «ERP/CRM × размер/сектор» — в Tempus-API не идентифицированы; пресс-релиз даёт только тотал (21,1 %) и три сектора. Заменено данными Eurostat (это те же данные INE).
2. INE/Eurostat: комбинация «отрасль × размер 50–249» для Испании за 2025 — нет в открытых датасетах; есть только старая INE-таблица I кв. 2023 `[>24 мес]`.
3. ONTSI «Indicadores de uso de IA en España, Edición 2026 (datos 2025)» — PDF найден в выдаче, но сайт ONTSI отдаёт 403; содержимое не прочитано.
4. CRM по размеру/отраслям (Eurostat, 2023–2025) — API пустой; в INE не получено.
5. DIRCE: 4-значные классы CNAE (66.22, 52.29, 69.20, 69.10, 68.32) — в публикуемых таблицах только группы (3 знака); страта 200–499 отсутствует (есть 200–249 и 250–999).
6. Eurostat SBS: ряд ячеек по размеру конфиденциальны (напр., I55 20–49/50–249, F 250+, G46 250+, K 50–249).
7. Россия: число средних (101–250) и малых (16–100) предприятий **по отраслям** — статистика реестра ФНС только интерактивная; текстовые источники дают лишь тотал средних (>22 тыс., 07.2025).
8. Россия: данные АНО «Цифровая экономика», Минцифры, «Яков и Партнёры» по доле среднего бизнеса с ИИ — не получены (сайт Я&П недоступен из среды; остальные не найдены при исчерпанном лимите поиска). Показатели по группам 101–250 и 251–500 у ИСИЭЗ — только на графике, в тексте нет.
9. Казахстан: средние предприятия по отраслям (есть только в xlsx-приложениях); внедрение ИИ в бизнесе РК — не искалось.
10. Агрокомпании (CNAE 01) в Испании — DIRCE не охватывает; в Cifras PYME сектор «Agrario» есть только в агрегате (882 средних предприятия, 8 898 малых).

## Что сомнительно

1. INE-таблица tpx=59891 датирована I кв. 2023 (подтверждено заголовком на сайте INE), т.е. `[>24 мес]`; использовать только для относительного ранжирования секторов, не для абсолютных уровней 2025.
2. Eurostat 20,27 % vs INE 21,1 % для Испании 2025 — разный отраслевой охват; в питче указывать источник явно.
3. Число средних предприятий Испании: DIRCE 21 307 (50–249, 1.1.2025) vs Cifras PYME 28 373 (50–249, 11.2025, Seguridad Social, включая агросектор) — методологическое расхождение ~7 тыс.
4. Россия: 6,835 млн субъектов МСП на январь 2026 («Мой бизнес») против 6,6 млн на 10.07.2026 (naloger.ru со ссылкой на ФНС) — одно из чисел, вероятно, относится к другой дате/методике; для питча брать только цифры ФНС/РИА (6,4 млн на 10.07.2025; >22 тыс. средних).
5. ONTSI 2025 «20,5 %» — только из поискового сниппета.
6. «CRM 28,51 % предприятий ЕС» (Statistics Explained) — год значения не установлен.
7. Eurostat SBS содержит округлённые/оценочные значения занятости (кратные тысячам) — так в источнике; для точных расчётов долей использовать агрегаты B–S.
8. Классификация размеров в РФ (средние 101–250) и РК (средние 101–250 по Предпринимательскому кодексу) отличается от ЕС (50–249) — не сопоставлять напрямую `[определение РК приведено по памяти, не верифицировано в этой сессии]`.
