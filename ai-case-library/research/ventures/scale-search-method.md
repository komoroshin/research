# Метод поиска масштабных гипотез в энергетике

Разработан 01.09.2026 по запросу: найти в энергетике гипотезы масштаба
«направляющих King Slide», не требующие владения профильными бизнесами за
рубежом. Метод повторяемый — детекторы можно прогонять по любой отрасли.

## Рамка: чему должна соответствовать гипотеза

Пять фильтров, все обязательные:

1. **Неизбежно** — нужно каждой единице рынка, обойти нельзя.
2. **По штуке на единицу** — объём продаж растёт вместе с рынком, а не с нашей
   командой.
3. **Скучно** — настолько, что сильные игроки не считают это призом.
4. **Стандартизовано** — одно и то же для всех клиентов, без проекта под каждого.
5. **Распространяется без владения активами** — продаётся через интернет,
   живёт на публичных данных или на документах, которые клиент приносит сам.
   (Прецедент: Drillinginfo/Enverus построен на публичных регуляторных данных
   без владения ни одной скважиной; выход 6+ млрд $.)

Плюс сверка с командой: документы, LLM, голос, продакшн-инженерия — да;
физика сети, железо, полевые датчики — нет.

## Почему гипотезы не «придумываются», а «детектируются»

Все сильные находки этой сессии пришли не из брейнсторма, а из структурных
асимметрий: разрыв «начислено-собрано» — из цифр собираемости, голосовая
пустота в энергетике — из подсчёта по базе кейсов, слепая зона подстанций —
из анализа PJM. Метод превращает эти случайные находки в повторяемые операторы.

## Восемь детекторов

| # | Детектор | Что ищет | Уже найденный пример |
|---|---|---|---|
| D1 | **Начислено ≠ получено** | Место в цепочке, где право на деньги есть, а конверсия в деньги теряется | Акты: собирается 23–51% начисленного |
| D2 | **Меряют не то** | Отрасль меряет прокси, а упирается в другое | Рейтинг провода при узком месте в подстанции |
| D3 | **Обязаны, но не умеют** | Новая регуляторная обязанность с дедлайном и без инструментов | ЕПГУ для техприсоединения с 01.01.2026 |
| D4 | **Очередь** | Везде, где есть очередь, её обработка — продукт | Очереди на подключение: 2 000+ ГВт |
| D5 | **Один считает, другой платит** | Разъехавшиеся стимулы рождают нишу нейтрального измерителя | M&V гибких подключений |
| D6 | **Ничья бумага** | Документопоток между сторонами, который не принадлежит ни одной | Договор о гибкости utility–ЦОД: стандарта не существовало на июнь 2026 |
| D7 | **Умер лидер** | Доказанная ценность без монетизации = не тот покупатель; перезайти с другим | NewGrid: экономия 18–44 млн $/год при ~125 тыс. $ привлечённых |
| D8 | **Асимметрия базы кейсов** | Приём доказан в 5+ отраслях, в энергетике 0–1 кейс | Голос: 21 кейс в базе, в энергетике 1 |

## Первый прогон D8 — по всей базе (277 кейсов), 01.09.2026

Скрипт: подсчёт кейсов по механизму ИИ и бизнес-процессу, другие отрасли
против энергетики. Крупнейшие разрывы:

| Приём | Другие отрасли | Энергетика |
|---|---|---|
| Инспекция компьютерным зрением (cv-inspection) | **32** | **0** |
| Компьютерное зрение как механизм | 66 | 1 |
| Обработка документов | 28 | 1 |
| Классификация текста (nlp-classification) | 46 | 0 |
| ИИ-агенты | 28 | 0 |
| Планирование и диспетчеризация (scheduling-dispatching) | 18 | 0 |
| Document AI | 17 | 0 |
| Юридика и комплаенс | 15 | 0 |
| Полевые операции | 10 | 0 |

Детектор задним числом воспроизвёл обе сегодняшние находки (документы,
маршрутизация бригад) и дал одну новую крупную: **визуальная инспекция** —
самый воспроизводимый приём базы (32 кейса в 7 отраслях), в энергетике ноль,
при том что отрасль состоит из осмотров: ЛЭП, изоляторы, подстанции, опоры,
тепловизия. Занятость снаружи проверяется в волне 1 (известные игроки в
смежном: AiDASH — растительность со спутников, Gridware — датчики).

## Волны исполнения

**Волна 1 — прогон детекторов** (параллельные исследования, 1 день):
- A1: перепись размножающихся единиц энергоперехода (МВт, подключения,
  накопители, счётчики, сделки, инспекции, документы) с темпами роста и
  обязательной бумагой на каждую единицу — питает D1, D4, D6.
- A2: детектор D3 — новые регуляторные обязанности в энергетике 2025–2028
  по юрисдикциям, с дедлайнами и без инструментов.
- A3: детекторы D1, D5, D6 — разрывы конверсии денег и ниши нейтрального
  измерителя по всей цепочке стоимости.
- A4: детектор D7 — категории с доказанной ценностью и провалившейся
  монетизацией; у каждой — причина смерти и кандидат «тот же продукт,
  другой покупатель».
- A5: проверка занятости трёх крупнейших разрывов D8: визуальная инспекция
  сетевых активов, диспетчеризация бригад, document AI для энергетики.

**Волна 2 — сведение** (после волны 1): лонглист → пять фильтров →
шорт-лист 2–3 гипотезы с формулировками.

**Волна 3 — проверка**: шорт-лист через `idea-check`, по паспорту на гипотезу.

## Правила исполнения

Те же, что во всех проверках сессии: каждое число с источником, опровержения
ценнее подтверждений, некролог обязателен, «не нашёл» — полноценный ответ,
допущения помечаются словом «допущение».
