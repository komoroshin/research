# Дека «Новый участник экономики» — Океан Тех

Питч-дека на 30 слайдов: три института для нового участника экономики — Труд, Личность, Капитал.

## Стиль

Чёрно-белый, повторяет `../grid-9block-deck-bw`: белый фон, чёрный текст, серые рамки, Arial для контента и Courier New с разрядкой для надзаголовков. Единственный акцент — инверсия: чёрная плашка с белым текстом, ею помечено то, к чему ведёт слайд.

## Как собрать

```
node _build_pitch_bw_pptx.cjs
soffice --headless --convert-to pdf output/pitch.pptx --outdir output
```

Нужен `pptxgenjs` (`npm install pptxgenjs`) и LibreOffice Impress для PDF.

## Что где

- `_build_pitch_bw_pptx.cjs` — сборщик, единственный источник текста и чисел. Слайды в файле идут по порядку и подписаны номерами.
- `_team/bw/` — чёрно-белые фото команды для слайда 27.
- `output/pitch.pptx`, `output/pitch.pdf` — сама дека.
- `output/numbers.md` — все числа деки с указанием слайда: что рыночный пример и подлежит замене, что публичный факт.
