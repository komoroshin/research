# Общий контекст для venture-тем (база для трёх сессий)

Дата выгрузки: 2026-08-31. Источник: стратегическая сессия Константина Морошина
(глава Центра исследований «Океан Тех») по переиспользованию наработок компании
в новые продукты. Этот файл — общая шапка; сами темы в соседних файлах:

- `grid-ai.md` — AI для энергоактивов (полигон: энергосети инвестора)
- `elder-companion.md` — голосовой компаньон для пожилых
- `voice-agent-qa.md` — QA/сертификация голосовых агентов

## Кто мы

«Океан Тех» — студия исследований и разработки ИИ (Москва): 48 проектов,
64 в штате, 32 клиента, 7 отраслей. Центр исследований (Морошин) + Департамент
разработки + Океан Фреймворк™. Клиентский каталог: komoroshin.github.io/research/solutions/.
Вход-продукт: исследование «где ИИ даёт эффект» — 150 000 ₽ / 2 недели
(методология: 4–6 интервью → разбор по протоколу → сверка с возможностями
моделей → оценка эффекта экономистом). Эту же методологию используем для
валидации новых venture-тем.

## Четыре редких актива (из проекта голосового детского компаньона)

1. Низколатентный полнодуплексный голосовой диалог с перебиваниями (~1 с).
2. Долгая память о человеке + детектор тревожных ситуаций.
3. Удержание персоны + модель-судья с регрессионным контуром (прогонщик
   сценариев, регрессия при смене модели у провайдера, детектор дрейфа персоны).
4. Офлайн/локальный инференс, чистый аудиотракт в шуме, данные не покидают контур.

## Стратегические решения (зафиксированы)

- **Международная структура с самого начала.** Продукт на РФ не строим:
  рынок маленький и ненадёжный. **РФ — полигон обкатки практик.**
- Из восьми исходных идей переиспользования главной ставкой выбрана
  **QA/сертификация голосовых агентов** (см. voice-agent-qa.md), лучшим
  B2C-направлением — **компаньон для пожилых** (см. elder-companion.md,
  вердикт: на деле B2B2C). **Grid-AI** — опция, открывшаяся благодаря
  инвестору с собственными энергосетями (см. grid-ai.md).
- Отвергнуты в глобальной рамке: hands-free для производства и голос в
  автопроме (козырь был в импортозамещении), лобовая телемедицина в США
  (регуляторика, Hippocratic с $404M), рекрутёр-скринер (Mercor $10B съел
  категорию), голосовой дневник (ноль доказанных комп).

## Ключевые внешние ориентиры, звучавшие в сессии

- Hippocratic AI: $3,5 млрд (Series C $126M, Avenir), 115 млн клинических
  взаимодействий — доказательство цены «клинической безопасности» голосового ИИ.
- Speak: оценка $1 млрд (Accel, OpenAI Fund) — дуплексный голос в языковом B2C.
- Mercor: $10 млрд — AI-рекрутинг как маркетплейс.
- Coval $31M / Hamming $4.3M / Cekura $2.4M — категория QA голосовых агентов
  сформировалась и финансируется.
