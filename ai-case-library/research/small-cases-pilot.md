# Пилотная разведка: каталог проектов «клиентского масштаба» ($80k–$1M)

Дата: 2026-08-27. Цель — до разворачивания полного пайплайна понять, извлекаются ли
из открытых источников кейсы AI-студий в бюджетной вилке $80k–$1M, и какие поля
реально доступны. Продукт обезличенный: без имён студий и клиентов.

## Выводы по источникам

### 1. Clutch.co — каркас каталога (подтверждено)

Профили студий отдаются целиком и содержат структурированные отзывы клиентов,
верифицированные платформой. Из каждого отзыва извлекается:

- **вилка бюджета** — раскрыта платформой ($10–50k / $50–200k / $200k–1M / Confidential);
- **сроки проекта** (месяцы начала и конца);
- **отрасль клиента и размер компании** (диапазон сотрудников);
- **что построено** (описание проекта из анкеты клиента);
- **результат** — часто с цифрами, со слов клиента;
- клиент **уже обезличен платформой** (должность вместо имени, часто без названия компании).

Замер добычи на двух профилях:

| Профиль | Отзывов | В вилке $50k–1M с AI-содержанием |
|---|---|---|
| ai-lab (10 отзывов) | 10 | 5 |
| HatchWorks AI (29 отзывов) | 29 (просмотрена выдача) | 4+ |

Каталог ML/AI-студий на Clutch — сотни компаний; у заметных студий по 20–100 отзывов.
Оценка воронки: 30–50 профилей → 200–400 отзывов → **60–120 кейсов в целевой вилке**.
На каталог из 80–100 кейсов материала достаточно.

Слабость: результаты — со слов клиента и грубые («+35% продаж за 4 недели»),
техническая детализация тонкая.

### 2. Habr / vc.ru (блоги студий) — слой детализации

Проверен разбор интегратора (антифрод-система для ритейлера): богатая техническая
фактура (стек, модели, данные), целевые метрики — но **нет бюджета, сроков, размера
команды**. Годится как второй источник для обогащения, не как каркас.

### 3. Workspace.ru — русскоязычный каталог кейсов агентств

34 460 кейсов, фильтры по отрасли/региону/инструментам (в т.ч. нейросети).
Карточка кейса: отрасль, регион, дата сдачи, состав команды (поимённо!). **Бюджета
нет** — только самоприсвоенный ценовой сегмент («Эконом/Средний/Бизнес/Премиум»)
как фильтр каталога. Пригоден как источник российских кейсов с сегментом вместо вилки.

### 4. Рейтинг Рунета — бюджета в карточках нет, отдельной AI-категории нет. Не каркас.

## Примеры извлечённых записей (обезличенный формат)

1. **Страховая компания (авто), 201–500 сотрудников, США.** AI-чат-бот, выдающий
   котировки без звонка оператору. Бюджет $50–200k, 7 месяцев.
   Результат (со слов клиента): +35% продаж за первые 4 недели.
2. **Софтверная компания, 51–200 сотрудников.** ML-модель + мобильное приложение
   (React Native) + веб-платформа. Бюджет $200k–1M, 10 месяцев. Результат: +30%
   вовлечённость, +15% продажи, +40% точность учёта запасов.
3. **Гематологическая клиника, 11–50 сотрудников.** Голосовой AI-агент и чат-бот
   для записи и запросов пациентов + автоматизация выставления счетов.
   Бюджет $50–200k, 3 месяца. Результат: сокращение времени ответа, высвобождение
   часов персонала.
4. **Инжиниринговая компания, 11–50 сотрудников.** Мониторинг производства:
   детекция аномалий, дашборды, интеграция с ERP/IoT. Бюджет $50–200k, 8 месяцев.
5. **IoT-компания.** Генеративный чат-ассистент на RAG-архитектуре. Бюджет $50–200k,
   5 месяцев. Результат: точность ответов 90%+.
6. **Оператор дроновой инфраструктуры.** Запросы к данным воздушного трафика на
   естественном языке (LLM + батч-пайплайны). Бюджет $200k–1M, 4 месяца, MVP в проде.
7. **Медицинская аналитика.** Платформа с приоритизацией пациентов и телемедициной.
   Бюджет $200k–1M.

Ни одна запись не требует имени студии или клиента — формат работает.

## Что меняется в схеме (проект)

Новые поля: `budget_band` (usd_10_50k / usd_50_200k / usd_200k_1m / undisclosed —
только из источника, без наших оценок), `duration_months`, `client_size`
(диапазон сотрудников), `source_platform` (clutch_review / studio_blog / catalog).
Шкала уверенности своя: «подтверждено верифицированным отзывом клиента» /
«по данным исполнителя». Имена студий и клиентов не попадают в клиентскую проекцию
по построению (их нет уже в исходной записи; в internal-слое хранится URL источника).

## Открытые вопросы к продукту

1. **Ссылки на источники vs обезличенность.** Ссылка на отзыв Clutch раскрывает
   студию в один клик. Рекомендация: во внутренней версии URL хранится (проверяемость),
   в клиентской вместо ссылки — плашка «верифицированный отзыв клиента, Clutch,
   <месяц год>».
2. **Российские кейсы без бюджета.** Вилка бюджета есть только у Clutch. Для
   русскоязычных кейсов (Workspace/Habr) — либо ценовой сегмент площадки, либо
   честное «бюджет не раскрыт». Своих оценок не выдумываем.
