# Профиль проекта: Threshold (репозиторий komoroshin/research)

Продукт: приложение-протокол клинического уровня (первый протокол —
пищевая непереносимость/СРК, дальше сон, давление, нагрузка). Питч-дека —
HTML-слайды в `preza-threshold/`, публикация на GitHub Pages через `main`.

## Где контент

Весь текст деки — `preza-threshold/content.js`, внутри
`window.DECK = String.raw\`...\``. DSL:

- `=== slide N | layout: X` / `=== appendix N | layout: X [| internal]`
- `# заголовок`, `- буллеты`, `[big] значение | подпись`,
  `[time] Год N | подпись`, `[img] путь`, `| ячейки таблицы |`,
  `!! [Метка] текст` (акцентная рамка в любой раскладке), `> сноска`
- `--- notes` — заметки спикера. **Никогда не публикуются.**

Раскладки: title, statement, dense, phases (SVG-схема четырёх фаз, подписи
≤3 строк), timeline, metric, levels, risks и др. Пустая строка — разделитель
блоков (phases зависит от этого; следить, чтобы не вписать невидимый символ).

## Проверки — все, после любой правки

```
cd preza-threshold
node check.mjs           # механика + утечка заметок (маркерная фраза)
node touch-test.mjs      # мобильная версия
node check-numbers.mjs   # точность чисел, плотность (лимит 900),
                         # запрещённые формулировки, блок «Требует решения»
node make-public.mjs && node verify-public.mjs   # публичная копия
npm run pdf              # PDF (make-pdf.mjs)
python3 gen-design-export.py   # выгрузка для Клод Дизайна — не руками!
```

Переполнение слайдов — одноразовый playwright-скрипт, вызывающий
`window.deckOverflows()`; chromium лежит в `/opt/pw-browsers/chromium`.
Любая вставка/переформулировка текста может дать переполнение — проверять
всегда, лечить сокращением текста (вырезанное — в заметки), не CSS-хаками.

## Вставка слайда = перенумерация

Порядок, выработанный на четырёх вставках:

1. Заголовки `slides['slide N']` переименовывать **в убывающем порядке**;
   при коллизии цепочки — через временное значение (999).
2. Inline-литералы чинить **до** циклов переименования переменных `sN`.
3. Ссылки в прозе (README, письма, заметки) сверять по карте тем, а не
   только grep'ом по числу.
4. «Слайд N» с большой буквы ускользает от lowercase-grep — искать оба
   регистра.
5. Исторические разделы README не перенумеровывать — ставить пометку эпохи.

## Постоянные ограничения

- Ветка разработки: `claude/additional-research-9yw7zd`. В `main` идут
  только папки готовых артефактов; настройки репозитория не трогаем;
  PR не создавать без явной просьбы.
- Заметки спикера и internal-приложения не должны попадать в публичную
  копию и PDF (маркерные фразы зашиты в check.mjs / verify-public.mjs;
  при смене формулировки-маркера обновить обе проверки).
- Никаких скриншотов и логотипов конкурентов в деке.
- Никаких формулировок про диагноз, лечение, медицинские обещания —
  позиционирование «протокол с доказательной базой, не диагноз и не
  лечение».
- Единственная иллюстрация — схема фаз; остальные изображения — скриншоты
  собственного прототипа.
