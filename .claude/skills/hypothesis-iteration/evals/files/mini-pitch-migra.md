# Migra — протокол ведения мигрени без лекарств

## Проблема

Мигренью страдают миллионы людей, многие теряют рабочие дни. Существующие
приложения просто ведут дневник приступов — фиксируют, но не ведут к
результату.

## Решение

Migra ведёт человека по структурированному протоколу: выявление триггеров
(еда, сон, стресс), элиминация, постепенный возврат, профилактика.
Распознавание еды по фото, интеграция с трекерами сна.

## Модель

Подписка $19/мес. Рынок огромный, конкурентов мало.

## Команда

Основатель — продакт с опытом в health-приложениях; клинический
консультант — невролог.
