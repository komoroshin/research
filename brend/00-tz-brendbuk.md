# ТЗ на брендбук Threshold

**Что делаем.** Одну HTML-страницу на токенах дизайн-системы: открывается в
браузере, печатается в PDF, обновляется вместе с системой. Figma не заводим —
источник истины уже в CSS.

**Зачем.** По ней подрядчик печатает, застройщик собирает стенд, новый дизайнер
понимает правила без нас.

## На чём стоит

Шесть смыслов. Из них выводится всё остальное.

1. **Возвращение, а не ограничение.** На выходе еды больше, чем на входе.
2. **Личное исследование.** Никто не проведёт его за человека, мы проводим
   через него. Мутная середина — часть метода, а не сбой.
3. **Мир полевой науки — в фоне.** Журнал, накопление, терпение. Наружу
   словарём не выходит: ни экспедиций, ни компасов, ни карт.
4. **Расследуем дни, а не еду.** Наблюдение → зацепка → версия → ответ. Еда не
   обвиняемый. Отпавшая версия — хорошая новость.
5. **Честность тем же кеглем.** Оговорка не мельче тела минус шаг, никогда
   петитом.
6. **Достоинство.** Имя ничего не сообщает окружающим — знак не должен тоже.

Линии: «Ответ уже в ваших днях» — обещание. «Ваше личное исследование» —
определение продукта.

## Разделы

Идея · Голос · Имя и знак · Цвет · Шрифт · Графика · Применения · Чего никогда.

Голос, цвет и шрифт переносятся из дизайн-системы почти готовыми. Идея, знак,
графика и применения пишутся с нуля.

## Правила работы

- Ничего нового сверх системы: ни цвета, ни шрифта, ни иллюстрации, ни
  пиктограммы.
- Знак растёт из черты 64×2 — единственного орнамента системы, который уже
  означает границу.
- Каждое правило ссылается на смысл из списка выше. Без основания — вырезаем.
- Вне приложения forest можно лить полем, внутри — нет.

## Приёмка

1. Знак читается в 16 px, не выдаёт тему, работает в один цвет.
2. «Чего никогда» — не меньше десяти проверяемых запретов.
3. «Применения» дают размеры и материалы, а не настроение.
4. Страница печатается в PDF без потерь содержимого.
